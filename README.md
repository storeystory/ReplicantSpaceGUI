# Welcome!
This project is a GUI intended for use with [Replicant Space](https://replicant.space/), an extremely cool API-first space exploration, resource management, sandbox game. Follow the [quickstart](https://replicant.space/docs/quickstart/) to make an account and get an API key, add it to config.json.example and get rid of the .example extension.

Then, `pip install PySide6 requests`, then from the project directory `python main.py`. That should get you rolling.

Proper built releases to come!

Built in Qt Creator with the help of an LLM. I use AI as a tool -- it's not doing all the work for me, and I never commit/run code that I don't fully understand.
